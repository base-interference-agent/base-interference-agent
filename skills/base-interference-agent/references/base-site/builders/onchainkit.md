 Find where retired, moved, and renamed Base products went, including OnchainKit, MiniKit and mini apps, the Base Account SDK, Base MCP, Basenames, and Base App.

 Copy page Copy page 

 Several products and guides that Base docs used to cover are now retired, documented elsewhere, or renamed. Find the product below to see its status and where to go now. Older links to these products redirect to the matching section on this page. 
 Product Status Where to go now OnchainKit Retired wagmi , viem , and Coinbase Developer Platform MiniKit and mini apps Retired A standard web app, registered on the Base Dashboard Base Account SDK and Smart Wallet Moved Coinbase Wallet SDK on Coinbase Developer Platform Base MCP Moved Wallet MCP on Coinbase Developer Platform Basenames Docs moved Basenames FAQ on Coinbase Developer Platform Base App Renamed Coinbase Wallet 

 Retired 

 OnchainKit 

 OnchainKit ( @coinbase/onchainkit ) was a React component library for onchain apps, with wallet, transaction, swap, fund, checkout, and identity components and the MiniKit hooks for mini apps. 
 Status: Deprecated and no longer maintained. The GitHub repository is archived, and there is no replacement library. 
 Where to go now: 

 Build wallet connection, reads, and transactions directly with wagmi and viem .

 Use Coinbase Developer Platform for services that OnchainKit components wrapped, such as Paymaster gas sponsorship.

 MiniKit and Mini Apps 

 Mini apps were Farcaster-style apps that ran inside Base App, built with MiniKit, a manifest, and the mini app SDK. 
 Status: Sunset. Base App, now Coinbase Wallet , supports standard web apps in its in-app browser, so your app or site does not need a manifest, MiniKit, or any other special integration to work there. 
 Where to go now: 

 Build a standard web app with wagmi and viem .

 To have your app listed in the app, register it on the Base Dashboard .

 The Farcaster mini app specification is maintained at miniapps.farcaster.xyz .

 Moved 

 Base Account SDK 

 The Base Account SDK connected apps to smart-contract wallet accounts for sign-in, payments, gas sponsorship, and spend permissions. Older Smart Wallet guides also point to this section. 
 Status: The documentation moved to Coinbase Developer Platform as the Coinbase Wallet SDK. The package is still @base-org/account , and Coinbase Developer Platform recommends it until the next-generation Coinbase Wallet SDK is ready. 
 Where to go now: Use the Coinbase Wallet SDK documentation . 
 Base MCP 

 Base MCP was an MCP server that connected an AI assistant to a user’s wallet to check balances, send funds, swap tokens, and sign messages. 
 Status: The documentation moved to Coinbase Developer Platform, where the product is now called Wallet MCP. 
 Where to go now: Use the Wallet MCP documentation . 

 Wallet MCP is a different product from the Base docs MCP server at https://docs.base.org/mcp , which gives AI assistants search access to these docs. See Base docs MCP . 

 Basenames 

 Basenames are onchain names on Base, such as yourname.base.eth . 
 Status: The product is live. Its documentation moved to Coinbase Developer Platform. 
 Where to go now: 

 Register or manage a name at base.org/names .

 Read the Basenames FAQ on Coinbase Developer Platform.

 Renamed 

 Base App 

 Base App is the consumer app for Base. 
 Status: Renamed to Coinbase Wallet. The app is not retired. 
 Where to go now: Get the app at wallet.coinbase.com and find support in the Coinbase Wallet help center . Its mini app guides are covered in MiniKit and mini apps . 
 Retired Protocol Features 

 Flashblocks were retired when the Denim upgrade activated. To move an integration to 200ms native blocks, see Migrate From Flashblocks .
