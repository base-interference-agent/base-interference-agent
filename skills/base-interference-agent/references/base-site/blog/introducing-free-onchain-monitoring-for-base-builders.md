# Introducing free onchain monitoring for Base builders

> TL;DR: Base’s decentralization roadmap focuses on transparency and enhancing onchain security. To support this, we’re committed to fostering a secure environment for onchain…

- Date: 2024-10-29
- Author: Base
- URL: https://www.base.org/blog/introducing-free-onchain-monitoring-for-base-builders

**TL;DR:** Base’s decentralization roadmap focuses on transparency and enhancing onchain security. To support this, we’re committed to fostering a secure environment for onchain builders. Today, we’re announcing access to free smart contract monitoring and analytics for every app and protocol on Base, powered by Hexagate. [Apply now](https://bit.ly/hexagateforbase).

## Building Base with a security-first approach

From day one, Base has been built with a [security-first approach](https://base.mirror.xyz/_SiAx8dQRYJJ4lygkJc0QvBKvf16VVm7_-mdWMdFv20) — combining Coinbase's enterprise-grade practices with an open-source codebase. At the chain level:

- Base is built on the secure, open-source OP Stack with Optimism, benefiting from extensive audits and community security efforts.
- Coinbase's Protocol Security team thoroughly audited Base, enhancing security and ensuring no critical vulnerabilities before mainnet launch.
- Before mainnet launch, Base engaged over 100 security researchers in a public audit contest, strengthening Base's security through broad community input.

To bring the next billion users onchain, we’re now looking to empower builders with the tools they need to build secure, reliable apps and protocols for their users. A critical component of this is smart contract monitoring, enabling builders to detect potential threats to their app or protocol and take action. But onchain monitoring is expensive, time-consuming, and difficult for builders to set up.

Now, we're taking a major step towards this by offering access to free smart contract monitoring, detection, and analytics for every app or protocol on Base by partnering with [Hexagate](https://www.hexagate.com/).

## Empowering builders on Base with advanced security tools

For the past year, the Base core team has leveraged Hexagate’s solutions to improve security on Base — using its threat detection ML models, invariant monitoring, and risk intelligence to proactively enhance Base’s security.

These solutions monitor foundational assets, like cbBTC, as well as sophisticated smart contract systems like fault proofs, to deliver comprehensive, real-time insights. Earlier this year, we successfully completed a [SEAL Wargame Simulation](https://www.coinbase.com/blog/strengthening-our-defenses-with-seal-wargame-simulations) using the Hexagate platform to stress test our security protocols against incidents.

Through our collaboration with Hexagate, **every builder on Base** now has free access to tools that enable early threat detection and proactive risk mitigation.

### How it works

Builders on Base can now use Hexagate’s enterprise-grade platform to secure their apps and protocols with:

- **Hexagate Ecosystem Tier:** Real-time, ML-based threat monitoring for up to 10 contracts on Base — plus 5 custom monitors for known threats for these contracts _for free_.
- **Real-Time Alerts:** Immediate notifications that can be forwarded through channels like Slack, Telegram, or email.
- **Guidance and Support:** Documentation and tutorials on setting up monitors, triage alerts, and responding to incidents.

Starting today, anyone can apply for the Hexagate Ecosystem Tier [here](https://bit.ly/hexagateforbase) — and for builders in need of more advanced features, Hexagate offers a full suite of services at a discounted fixed rate for the first year.

## Building a more secure onchain future

We’re committed to fostering a secure and transparent environment for onchain builders, starting with access to smart contract monitoring and progressively rolling out more features, so that every app and protocol on Base can innovate with confidence.
