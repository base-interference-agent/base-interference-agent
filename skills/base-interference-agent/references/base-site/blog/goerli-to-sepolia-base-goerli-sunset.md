# Goerli to Sepolia: Base Goerli Sunset

> In October, we announced that Base would be moving our test network (“Base Testnet”) from Goerli to Sepolia. The transition is complete and Base Goerli has been sunset.

- Date: 2024-02-09
- Author: Base
- URL: https://www.base.org/blog/goerli-to-sepolia-base-goerli-sunset

In October, [we announced](https://base.mirror.xyz/kkz1-KFdUwl0n23PdyBRtnFewvO48_m-fZNzPMJehM4) that Base would be moving our test network (“Base Testnet”) from Goerli to Sepolia. The transition is complete and Base Goerli has been sunset.

As of today, Base Sepolia will be the only Base Testnet. Please review the [Base Docs site](https://docs.base.org/?utm_source=base_dot_org) and the information below to get started with Base Sepolia.

**Base Sepolia Resources**

- [Network information](https://docs.base.org/network-information?utm_source=base_dot_org#base-testnet-sepolia)
- [Contract information](https://docs.base.org/base-contracts?utm_source=base_dot_org#base-testnet-sepolia-1)
- [Base Sepolia Bridge](https://sepolia-bridge.base.org/)

If you have any questions or need technical support while getting started with the new test network, please reach out and open a ticket in the #developer-support channel in the [Base Discord](https://base.org/discord).
