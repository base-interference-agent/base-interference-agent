# Goerli to Sepolia: Important Dates and Information

- Date: 2024-01-12
- Author: Base
- URL: https://www.base.org/blog/goerli-to-sepolia-important-dates-and-information

In October, [we announced](https://base.mirror.xyz/kkz1-KFdUwl0n23PdyBRtnFewvO48_m-fZNzPMJehM4) that Base will be moving our test network from Goerli to Sepolia. Now that we’re getting closer to [the end of Goerli support by Ethereum client and EF testing teams](https://blog.ethereum.org/2023/11/30/goerli-lts-update), we want to provide users and developers with an update on important dates and information.

**Important Dates**

- **1/19/2024 -** Deposit functionality on the [Base Goerli bridge](https://goerli-bridge.base.org/deposit) will be paused
- **1/31/2024 -** [Base docs](https://docs.base.org/?utm_source=base_dot_org) will no longer reference Goerli
- **2/9/2024 -** Base Goerli infrastructure (including the Base Goerli bridge UI) will be spun down

As you are making your migration from Base Goerli to Base Sepolia, please keep in mind that Base Sepolia is a separate network and will require network configuration changes. To get started on Base Sepolia, please visit our [docs site](https://docs.base.org/?utm_source=base_dot_org) for [network](https://docs.base.org/network-information?utm_source=base_dot_org#base-testnet-sepolia) and [contract](https://docs.base.org/base-contracts?utm_source=base_dot_org#base-testnet-sepolia) details.

While Goerli bridging is not subject to the same 7 day challenge period as mainnet, we recommend that users bridge their testnet funds from Base Goerli to Ethereum Goerli well in advance of our infrastructure being spun down on **2/9/2024.** This can be done on the [Base Goerli Bridge](https://goerli-bridge.base.org/withdraw).

If you have any questions or need technical support during your migration, please don’t hesitate to reach out and open a ticket in the [Base Discord](https://base.org/discord).
