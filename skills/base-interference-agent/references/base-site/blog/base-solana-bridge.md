# The Base-Solana bridge is now live, secured by Chainlink & Coinbase

> TL;DR: The Base-Solana Bridge is now live on mainnet. Secured by Chainlink CCIP alongside Coinbase, the bridge lets builders on Base support Solana assets in their apps, users…

- Date: 2025-12-04
- Author: Base
- URL: https://www.base.org/blog/base-solana-bridge

**TL;DR:** The Base-Solana Bridge is now live on mainnet. Secured by Chainlink CCIP alongside Coinbase, the bridge lets builders on Base support Solana assets in their apps, users trade Solana assets on Base, and communities tap into liquidity across Base and Solana. The bridge is now live on mainnet for builders to integrate, and rolling out for anyone to use in apps like Zora, Aerodrome, Virtuals, Flaunch, and Relay.

---

## **A bridge, not an island**

To build a global economy, we need to make it interoperable and connected; and being a bridge, not an island, has been a core value of Base since [day one](https://www.base.org/blog/meet-base). If we want to bring the world onchain, we need to make it dead simple for people to move assets at the speed of the internet, discover new apps no matter which chain they’re built on, and unlock value wherever it exists.

**To make this vision a reality, we’re excited to launch a new** [**bridge between Base and Solana**](https://github.com/base/bridge)**, enabling anyone to move assets across both ecosystems.**

The bridge is now live on mainnet and rolling out for anyone to use in apps including [Zora](https://zora.co/), [Aerodrome](https://aero.drome.eth.limo/launch), [Virtuals](https://app.virtuals.io/), [Flaunch](https://bridge.flaunch.gg/), and [Relay](https://relay.link/bridge/base?fromChainId=792703809&fromCurrency=11111111111111111111111111111111&toCurrency=0x311935cd80b76769bf2ecc9d8ab7635b2139cf82). Users will be able to trade [SOL](https://x.com/solana), [CHILLHOUSE](https://x.com/ChillHouseSOL), [TRENCHER](https://x.com/Trencher_Sol), and many more Solana assets on Base.

The bridge is secured by Chainlink's [Cross-Chain Interoperability Protocol (CCIP)](https://chain.link/cross-chain), via a bespoke cross-chain oracle, alongside Coinbase. Coinbase and Chainlink CCIP node operators each independently verify all messages, ensuring token transfers between Base and Solana are safe and reliable.

## **What the Base-Solana bridge unlocks**

The bridge enables movement of assets across Base and Solana, allowing anyone to deposit and use SOL in Base apps, import any Solana asset into Base, and export any Base asset into Solana. This opens up a range of new cross-chain experiences:

- Base builders can integrate the bridge to support Solana assets (SOL and SPL tokens) natively in their apps.
- Users can trade and use assets across chains in apps that integrate the bridge, regardless of whether they're on Base or Solana.
- Anyone can bridge assets between Base and Solana to make them tradable and usable on both chains.

The Base-Solana bridge is [open-source on GitHub](https://github.com/base/bridge) and available for any developer to integrate into their app on mainnet, so they can support Solana assets natively and deliver smooth cross-chain experiences. [See the docs](https://docs.base.org/base-chain/quickstart/base-solana-bridge?utm_source=base_dot_org) and start building.

## **Building an open & connected economy for everyone**

This is a major step towards our goal for Base to serve as a hub for the everything economy: every asset, across every network, at any time, and Solana is just the beginning.

If you’re a builder, [see the docs](https://docs.base.org/base-chain/quickstart/base-solana-bridge?utm_source=base_dot_org) to integrate the bridge and support assets across Base and Solana. If you’re a user, the bridge is rolling out for anyone to use in apps including [Zora](https://zora.co/), [Aerodrome](https://aero.drome.eth.limo/launch), [Virtuals](https://app.virtuals.io/), [Flaunch](https://bridge.flaunch.gg/), and [Relay](https://relay.link/bridge/base?fromChainId=792703809&fromCurrency=11111111111111111111111111111111&toCurrency=0x311935cd80b76769bf2ecc9d8ab7635b2139cf82).
