## Rules
- Use the address from this list, and confirm it on BaseScan before sending funds or adding it to a contract.
- Addresses here are on Base Mainnet only. The NVDA address in the o1 docs (stock-paired launches) is a different token context, so don't mix them up.
- Tokenized stocks may have transfer restrictions, and the asset isn't the same as owning the company's shares. Check the issuer's terms before buying.
- Trading or lending these carries market risk and, for lending, liquidation risk. Use the approval workflow in SKILL.md.
