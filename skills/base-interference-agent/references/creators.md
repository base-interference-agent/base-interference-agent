# Base creators (official sources)

Source: https://docs.base.org/get-started/creators (read on the date of this commit).

## Creator Grant Program
- Up to $4,000 for independent creators who already make content about Base.
- Eligible formats:
  1. Writers covering Base (deep dives, memes, analysis, threads)
  2. Streamers and live-show hosts
  3. Creators running a recurring podcast or show
  4. Independent video creators
  5. Educators covering Base in their own language
- Apply: https://forms.gle/sZ5cBADdXLfbbe1R8 (the docs say to apply to be included in the next cohort).
- Check the form for current cohort dates and terms. The docs don't list a deadline.

## Related Base programs (for builders, not creators)
- Builder Grant Program: https://forms.gle/urqjBJYJjR6Vqqre6 (see `sdks-index.md` for the details).
- Base Batches accelerator: https://www.base.org/batches
- Base Ecosystem Fund: https://www.base.org/ecosystem-fund

## What this file doesn't cover
- Posts or announcements on X (Twitter) and other social channels. They weren't read for this file, so don't treat them as verified.
- Creator payouts beyond the grant amounts above.

## Rules for answering
- Quote the eligibility and amount from this file, and link the official page.
- If a question isn't covered here, say so and point to https://docs.base.org.
- Don't promise a grant or payout. Only the program decides.
