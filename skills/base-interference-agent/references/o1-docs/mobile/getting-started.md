# Get started

> Create an o1 Mobile account, add USDC on Base, and place a first buy.

Install o1 Mobile from the official store listing, then use the steps below to open an account and place a first buy.

## Create your account

**1. Choose a sign-in method**

Continue with email, Apple, or Google. Email sign-in sends a six-digit code.

**2. Choose the right account**

If one email is linked to more than one account, the app asks you to pick one. Each account has its own wallets.

**3. Finish the short setup**

You can connect X and choose a username now, or leave those for later. If a follow step appears, follow the number of traders the screen asks for.

The app prepares wallet addresses on Solana, Base, BNB Chain, and Robinhood Chain. Wait until that setup finishes before you send funds. See [Networks](https://docs.o1.exchange/mobile/chains.md) for what each address is for.

## Add USDC

Buy routes spend USDC on Base. You can send USDC to your Base address, or open the Coinbase deposit flow where it is available. The choices and checks are on [Deposit](https://docs.o1.exchange/mobile/fiat-onramp.md).

## Place a first buy

Open a token from Market, Search, Feed, or a profile. Choose Buy, enter an amount, and read the quote before you confirm. The quote fields and the current minimum buy are explained in [Trading](https://docs.o1.exchange/mobile/decentralized-swaps.md).

> [!NOTE]
>
> A confirmed blockchain transaction cannot be reversed from the app. Check the token, network, amount, and quote before you confirm.
