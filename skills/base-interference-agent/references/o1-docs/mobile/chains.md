# Networks

> The chains o1 Mobile currently uses for trading, deposits, and wallet addresses.

o1 Mobile currently prepares an address and supports spot discovery and swaps on:

* Solana
* Base
* BNB Chain
* Robinhood Chain

A supported network does not mean every token on that network has a route. Availability depends on liquidity, market data, and the quote returned for that amount.

## One cash balance

The in-app cash balance is USDC on Base. Buys spend it, and sells return to it, including when the token is on another supported chain. Deposit USDC on Base only. The address and the Coinbase option are on [Deposit](https://docs.o1.exchange/mobile/fiat-onramp.md).

## Use the matching address

Account shows a separate address for Solana, Base, BNB Chain, and Robinhood Chain. Send an asset only to the address for its own network. A transfer on the wrong network can be unrecoverable.

Withdrawal destinations are a shorter list than the trading networks. The current withdrawal networks are on [Send and withdraw](https://docs.o1.exchange/mobile/send-and-withdraw.md).

> [!NOTE]
>
> The supported set can change. Use the networks shown in the app when you deposit, trade, or withdraw.
