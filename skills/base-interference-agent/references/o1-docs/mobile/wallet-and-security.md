# Wallet and security

> How the o1 Mobile wallet, biometrics, and key export work.

o1 Mobile provides a user-controlled embedded wallet powered by Turnkey. The wallet is created for your account and is used for deposits, swaps, sends, and withdrawals. Key export is available in Settings.

## Sign-in

You can sign in with email, Apple, or Google. Email sign-in uses a one-time code. If several accounts share an email, choose the account on the picker. Each account has its own wallets.

## Addresses

Account lists the addresses currently prepared for you:

* Base
* Solana
* BNB Chain
* Robinhood Chain

Copy the address that matches the asset and network you are receiving. Details are on [Networks](https://docs.o1.exchange/mobile/chains.md).

## Biometrics

On the Security screen you can require Face ID, fingerprint, or the device passcode for:

* opening the app
* withdrawing funds
* exporting keys

If the device has no biometrics enrolled, use the device passcode or turn biometrics on in system settings first.

## Export keys

Export is in Account. The app asks you to acknowledge that anyone with the exported key or recovery phrase can move the funds. o1 will not ask you for a private key, recovery phrase, one-time code, or device unlock code.

Activity in another wallet is not tracked as o1 Mobile activity. Portfolio figures and leaderboard placement can become inaccurate after you use the exported key elsewhere.

> [!WARNING]
>
> Store exported keys offline. Do not send them to support, and do not put them in chat, email, or screenshots.

Deleting the account does not move the assets. Export the keys first if you still need access to the funds. The delete flow is described on [Legal and support](https://docs.o1.exchange/mobile/legal-and-support.md).
