# SDKs & APIs

> SDKs, APIs, and command-line tools for identity verification, local development, and direct Base chain access.

Choose the SDK, API, or command-line tool that matches what your application needs. Base provides identity verification APIs, local development tooling, and direct chain APIs.

> [card] [Base Chain API](https://docs.base.org/base-chain/api-reference/rpc-overview.md)
>
> JSON-RPC, WebSocket subscriptions, and Debug tracing against Base nodes.

> [card] [Base Earn API](https://docs.base.org/sdks/base-earn/overview.md)
>
> Earn and borrow on Base from any wallet with unsigned, ready-to-sign transactions.

> [card] [Base Verify API](https://docs.base.org/sdks/base-verify/overview.md)
>
> Prove verified account ownership and enforce Sybil-resistant eligibility policies.

> [card] [Foundry for Base](https://docs.base.org/sdks/base-anvil.md)
>
> Build and test Base-native contracts locally with Foundry v1.8.4 or later.

## Which Surface Do I Need?

| You want to… | Use |
| - | - |
| Let users earn yield or borrow from their own wallet | [Base Earn API](https://docs.base.org/sdks/base-earn/overview.md) |
| Verify account ownership or enforce an identity policy | [Base Verify API](https://docs.base.org/sdks/base-verify/overview.md) |
| Build and test Base-native contracts locally | [Foundry for Base](https://docs.base.org/sdks/base-anvil.md) |
| Read balances, blocks, logs, or send raw transactions | [Ethereum JSON-RPC](https://docs.base.org/base-chain/api-reference/rpc-overview.md) |
| Stream new blocks and logs | [eth\_subscribe](https://docs.base.org/base-chain/api-reference/ethereum-json-rpc-api/eth_subscribe.md) |
| Migrate a Flashblocks integration | [Migrate From Flashblocks](https://docs.base.org/upgrades/denim/migrate-from-flashblocks.md) |
| Trace a transaction or block | [Debug API](https://docs.base.org/base-chain/api-reference/debug-api/debug_traceTransaction.md) |
