# Base

> The blockchain for global finance.

Base is built by Coinbase, trusted by leading institutions, and open to all. Stablecoin issuance, payments, and compliance controls ship as native chain primitives you can use out of the box, without building or auditing your own contracts. Transactions settle in under a second, and cost less than one cent.

> [card] [Tokenize Assets](https://docs.base.org/get-started/issue-rwa.md)
