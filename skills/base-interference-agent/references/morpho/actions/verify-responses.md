# Verify Actions API responses

Check simulation results and verify the signed proof before signing typed data or sending Actions API calls.

Source: https://docs.morpho.org/api/actions/verify-responses

The Actions API returns calls for the user's wallet to send. Morpho does not submit transactions. Verify the proof and inspect the response before signing typed data or sending calls.

## Check the response [#check-the-response]

| Field                                          | What to check                                                                                                                                                                                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `data.status`                                  | `prepared` contains wallet calls. Send them only after proof verification and a successful final simulation. `signature_required` asks for typed-data signatures, not call execution. Verify that response before asking the user to sign. |
| `data.chain_id`, `data.account`, `data.action` | Match the user's chain, account, and requested action.                                                                                                                                                                                     |
| `data.expires_at`                              | Reject an expired action and request it again. This off-chain validity timestamp does not control transaction inclusion.                                                                                                                   |
| `data.simulation.status`                       | Require `success` before sending calls. A `simulation_failed` response contains no wallet calls. Inspect `simulation.failure.code` and `simulation.failure.message` instead.                                                               |
| `data.simulation.wallet_changes`               | Compare each `asset` and signed `difference`, in asset base units, with the expected spendable balance change.                                                                                                                             |
| `data.simulation.position_changes`             | Compare protocol position changes with the user's intent. For a vault deposit, `vault_shares` is the signed change in share base units.                                                                                                    |
| `data.simulation.effects`                      | Check the action-specific effects. For a Vault V2 deposit, these include `gross_assets`, `referral_fee_assets`, and `net_assets`.                                                                                                          |

For `signature_required`, show the user each `signatures[].typed_data` and sign only with their consent. Check its domain chain against the requested chain. Post the returned `continuation` and collected signatures to the same action endpoint, then verify the new response. The TypeScript helper below limits this to three signature rounds and refuses to sign with 60 seconds or less remaining.

The final ordered calls, including prerequisite calls and collected signatures, are the authoritative simulation input. The attestor does not accept caller-selected state overrides. A successful simulation is a point-in-time check, not a guarantee of inclusion or of unchanged state when the wallet sends the calls. It does not prove the wallet can send them: wallets have their own gas estimates, batch limits, and atomic-batching support.

A proof reports what the attestor checked at that time. It does not make a transaction safe after its on-chain protections expire.

## Send calls from the wallet [#send-calls-from-the-wallet]

Send every call's `to`, `data`, and `value` unchanged, from the action's `account`, on its `chain_id`, in the returned order. Treat these fields as opaque. Do not set gas limits or gas prices from the simulation: the wallet estimates gas and applies its own size and gas limits.

* **Atomic batch:** use EIP-5792 `wallet_sendCalls` only when the wallet reports `atomic` support for that chain, or send one ERC-4337 user operation. All calls apply together or none do.
* **Sequential transactions:** otherwise send one call at a time and await its receipt before sending the next. Check `expires_at` before each call. Stop on the first rejection, failure, or expiry. Already-confirmed approvals and authorizations remain in place; the API does not revoke them. Show the user what was confirmed. Request the action again to retry instead of sending the remaining calls, so the new response reflects the confirmed state.
* **Typed-data support:** if the wallet cannot sign EIP-712 typed data with `signature_mode: "auto"`, request the action again with `signature_mode: "none"`. Tell the user before sending that the replacement approval or authorization calls can grant more than the signature would have, including an unlimited approval.

If a transaction may have been sent but its outcome is unknown, check its receipt or the wallet's history before retrying. Do not assume that an unconfirmed transaction failed.

### Retry or rebuild [#retry-or-rebuild]

Treat HTTP 503 state, request, and verification errors as retryable. On HTTP 429, honor `Retry-After`; no JSON error body is specified for that response. `SIGNATURE_REFRESH_REQUIRED` and `ACTION_CONTINUATION_INVALID` mean restarting the action without its continuation.

If the API is unavailable or rejects a request, integrators can build the transaction with the Morpho SDK using their own RPC, or call the protocol contracts directly. The [Blue transaction tutorial](/developers/blue/tutorials/assets-flow/) and [Midnight borrow tutorial](/developers/midnight/tutorials/borrow-at-a-fixed-rate/#execute-the-borrow) retain SDK and contract alternatives. Re-read current state and apply the relevant simulation, authorization, and user-consent checks; do not execute calls from a rejected response.

## Verify the signed proof [#verify-the-signed-proof]

Read the `Morpho-Action-Proof` response header. It is an ES256 compact JWT with protected header `typ: morpho-action-proof+jwt` and a `kid` identifying the verification key.

Send requests only to your keyed origin under `/v0/actions/`, with `x-api-key`, and do not follow redirects. The proof binds the path, not the host; a request sent elsewhere could be relayed with a genuine response.

Download Morpho's public signing keys from the same address you send requests to: `https://private.api.morpho.org/.well-known/morpho-actions-jwks.json`. This download needs no API key. Pin that address in your verifier. Do not accept a remote key source nominated by a proof header.

Cache JWKS for at most 60 seconds, as its `Cache-Control` header specifies, so removed keys stop being trusted quickly. Refetch when a proof's `kid` is absent from the cached set. Require a nonempty `kid` that identifies exactly one key. The TypeScript helper reloads an expired cache and refreshes an unknown `kid` subject to JOSE's cooldown; it rejects the proof if the key still does not resolve uniquely. The other helpers accept JWKS bytes, so their callers must implement this cache and refresh policy.

| Check           | Expected value                                                                                                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Algorithm       | `ES256`                                                                                                                                                                                                     |
| Protected `typ` | `morpho-action-proof+jwt`                                                                                                                                                                                   |
| `iss`           | `https://api.morpho.org/v0/actions`, the production issuer, not the private request origin                                                                                                                  |
| `aud`           | `morpho-actions-client`                                                                                                                                                                                     |
| `sub`           | `action-response`                                                                                                                                                                                           |
| Time            | Require safe-integer `iat` and `exp`, with `exp > iat` and `exp - iat <= 300` seconds. Reject expired proofs and an `iat` in the future or more than 60 seconds old, allowing 5 seconds of clock tolerance. |

Keep the exact request bytes sent and response bytes received. Hash those bytes with SHA-256 and encode the digest as unpadded base64url. Do not parse and reserialize JSON before hashing. Clients such as `fetch` that decode compression hash the decoded bytes.

| Signed binding                                                     | Compare with                                                                |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| `request.method`, `request.target`                                 | The sent HTTP method and path, including the query string when present      |
| `request.content_type`, `request.body_sha256`                      | The sent content type and hash of the exact request body                    |
| `response.status`, `response.content_type`, `response.body_sha256` | The received HTTP status, content type, and hash of the exact response body |
| `request_id`                                                       | The `x-request-id` response header                                          |
| `action_id`, `action`                                              | `data.action_id` and `data.action`                                          |
| `decision`                                                         | The decision derived from the response below                                |

Derive the decision independently and require the signed decision to match:

| Decision             | Response                                                                | Allowed wallet operation                                               |
| -------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `signature_required` | `data.status === "signature_required"`                                  | Request user-approved typed-data signatures, not call execution.       |
| `approved`           | `data.status === "prepared"` and `data.simulation.status === "success"` | Send calls only after the response, chain, expiry, and consent checks. |
| `rejected`           | Any other result                                                        | Do not send calls.                                                     |

Stop on a missing proof, failed signature verification, expired proof, or mismatched binding. A valid signature alone does not mean the action was approved. The proof does not prevent the same unchanged response from being presented again before it expires.

## Verification samples [#verification-samples]

For the Python examples, install Requests with `pip install requests`.

Keep the API key server-side. Browser apps should call through their own backend, leaving signing and sending to the user's wallet.

The TypeScript sample uses `jose` and reads `MORPHO_API_KEY` from the environment. Its `postAction` verifies the exchange; `runAction` also checks chain and expiry and handles signature continuations. Its abstract wallet adapter does not implement capability detection, sequential sending, receipt tracking, or retries: implement the sending rules above in that adapter. Inspect the simulated changes, match the sending account, and obtain user consent in your integration before wallet operations.

The Python, Java, and Go helpers below are the published verification helpers without changes. They accept raw request and response metadata and bytes plus JWKS bytes; they do not send requests or wallet calls. Use PyJWT with cryptography for Python, Nimbus JOSE JWT for Java, and `github.com/go-jose/go-jose/v4` for Go.

For those helpers, these examples capture the exchange without following redirects. Set `MORPHO_API_KEY` to your issued key and save the JSON request body as `request.json` first. Pass the printed HTTP status, response headers, exact file bytes, `POST`, the path below, and `application/json` to the helper. Treat non-success HTTP responses as errors; gateway errors may not be JSON.

The cURL examples save headers separately instead of using `--include`, so the body files contain only the exact response bytes.

Use a key issued for the private API origin below. A key for another API surface can return `403 Forbidden` before the Actions API validates the request body.

    ```ts
    import { base64url, createRemoteJWKSet, jwtVerify } from "jose";

    const API_ORIGIN = "https://private.api.morpho.org";
    // Current Morpho-issued usage-plan keys are not origin-restricted: keep them server-side.
    // Browser apps should call through their own backend.
    const API_KEY = process.env.MORPHO_API_KEY;
    // The environment's canonical issuer, not the host you call.
    const PROOF_ISSUER = "https://api.morpho.org/v0/actions";
    // Stop instead of signing forever if responses keep asking for signatures.
    const MAX_SIGNATURE_ROUNDS = 3;
    // The API finalizes a signature-required action only with more than 60 seconds left.
    const MIN_SIGNING_SECONDS = 60;

    const jwks = createRemoteJWKSet(
      new URL("/.well-known/morpho-actions-jwks.json", API_ORIGIN),
      { cacheMaxAge: 60_000 },
    );

    const sha256 = async (bytes: Uint8Array<ArrayBuffer>) =>
      base64url.encode(new Uint8Array(await crypto.subtle.digest("SHA-256", bytes)));

    interface ProofBinding {
      method?: string;
      target?: string;
      status?: number;
      content_type?: string;
      body_sha256?: string;
    }

    export interface ActionCall {
      to: `0x${string}`;
      data: `0x${string}`;
      value: string;
    }

    export interface ActionWallet {
      // Must show the EIP-712 typed data to the user and sign only after they approve it.
      signTypedData: (typedData: any) => Promise<string>;
      sendCalls: (chainId: number, calls: ActionCall[]) => Promise<unknown>;
    }

    // Returns the response data only when its Morpho-Action-Proof covers this exact exchange.
    export const postAction = async (path: string, payload: unknown) => {
      if (!API_KEY) throw new Error("Set MORPHO_API_KEY");
      const url = new URL(path, API_ORIGIN);
      if (url.origin !== API_ORIGIN || !url.pathname.startsWith("/v0/actions/")) {
        throw new Error("Not a Morpho action endpoint");
      }
      const contentType = "application/json";
      const requestBody = new TextEncoder().encode(JSON.stringify(payload));
      const response = await fetch(url, {
        method: "POST",
        headers: { "Content-Type": contentType, "x-api-key": API_KEY },
        body: requestBody,
        redirect: "error",
      });
      const responseBody = new Uint8Array(await response.arrayBuffer());
      const responseText = new TextDecoder().decode(responseBody);
      if (!response.ok) {
        // Gateway errors such as 429 or 502 may not use the JSON error envelope.
        const isJson = response.headers.get("Content-Type")?.startsWith("application/json");
        throw new Error(
          (isJson && JSON.parse(responseText).error?.message) ||
            `Morpho action request failed with HTTP ${response.status}`,
        );
      }
      const json = JSON.parse(responseText);

      const proof = response.headers.get("Morpho-Action-Proof");
      if (!proof) throw new Error("Missing Morpho-Action-Proof header");
      const { payload: claims } = await jwtVerify(proof, async (header, token) => {
        if (typeof header.kid !== "string" || !header.kid) {
          throw new Error("Missing proof key ID");
        }
        if (!jwks.fresh) await jwks.reload();
        const matchingKeys = () => jwks.jwks()!.keys.filter((key) => key.kid === header.kid);
        if (matchingKeys().length === 0 && !jwks.coolingDown) await jwks.reload();
        if (matchingKeys().length !== 1) {
          throw new Error("Proof key ID must identify exactly one key");
        }
        return jwks(header, token);
      }, {
        algorithms: ["ES256"],
        typ: "morpho-action-proof+jwt",
        issuer: PROOF_ISSUER,
        audience: "morpho-actions-client",
        subject: "action-response",
        requiredClaims: ["exp"],
        maxTokenAge: 60,
        clockTolerance: 5,
      });
      if (
        !Number.isSafeInteger(claims.iat) ||
        !Number.isSafeInteger(claims.exp) ||
        claims.exp! <= claims.iat! ||
        claims.exp! - claims.iat! > 300
      ) {
        throw new Error("Invalid proof lifetime");
      }

      const { data } = json;
      const decision =
        data.status === "signature_required"
          ? "signature_required"
          : data.status === "prepared" && data.simulation.status === "success"
            ? "approved"
            : "rejected";
      const request = (claims.request ?? {}) as ProofBinding;
      const signed = (claims.response ?? {}) as ProofBinding;
      const checks: [unknown, unknown][] = [
        [claims.request_id, response.headers.get("X-Request-Id")],
        [claims.action_id, data.action_id],
        [claims.action, data.action],
        [claims.decision, decision],
        [request.method, "POST"],
        [request.target, url.pathname],
        [request.content_type, contentType],
        [request.body_sha256, await sha256(requestBody)],
        [signed.status, response.status],
        [signed.content_type, response.headers.get("Content-Type")],
        [signed.body_sha256, await sha256(responseBody)],
      ];
      if (checks.some(([claimed, actual]) => claimed !== actual)) {
        throw new Error("Morpho-Action-Proof does not match this response");
      }
      return { data, decision };
    };

    // Runs an action on chainId: verifies every response before the wallet signs
    // or sends anything, and sends the calls only for an approved proof.
    export const runAction = async (
      wallet: ActionWallet,
      { chainId, path, body }: { chainId: number; path: string; body: unknown },
    ) => {
      const checkChain = (data: any) => {
        const chains = [data.chain_id, ...(data.signatures ?? []).map(
          ({ typed_data }: any) => Number(typed_data.domain.chainId),
        )];
        if (chains.some((id) => id !== chainId)) {
          throw new Error(`Action is not on chain ${chainId}`);
        }
        // Rejects a stale action; it does not control when a transaction is included.
        if (Date.now() / 1000 >= data.expires_at) {
          throw new Error("Action expired, request it again");
        }
      };

      let { data, decision } = await postAction(path, body);
      for (let round = 1; decision === "signature_required"; round++) {
        if (round > MAX_SIGNATURE_ROUNDS) throw new Error("Too many signature rounds");
        checkChain(data);
        const signatures = [];
        for (const { id, typed_data } of data.signatures) {
          if (data.expires_at - Date.now() / 1000 <= MIN_SIGNING_SECONDS) {
            throw new Error("Action expires too soon to sign, request it again");
          }
          signatures.push({ id, signature: await wallet.signTypedData(typed_data) });
        }
        ({ data, decision } = await postAction(path, {
          continuation: data.continuation,
          signatures,
        }));
      }

      if (decision !== "approved") {
        throw new Error(data.simulation?.failure?.message ?? "Action was not approved");
      }
      checkChain(data);
      return wallet.sendCalls(chainId, data.calls);
    };
    ```

    ```java
            || Math.rint(number.doubleValue()) != number.doubleValue()) {
    ```

    ```go
    ) (Result, error) {
    	if expectedIssuer == "" {
    		expectedIssuer = issuer
    	}
    	if now.IsZero() {
    		now = time.Now()
    	}
    	if !strings.HasPrefix(path, "/v0/actions/") || method != "POST" {
    		return Result{}, errors.New("request is outside the Actions API")
    	}
    	proof := header(headers, "morpho-action-proof")
    	if proof == "" {
    		return Result{}, errors.New("missing action proof")
    	}
    	parts := strings.Split(proof, ".")
    	if len(parts) != 3 {
    		return Result{}, errors.New("proof is not compact JWS")
    	}
    	protectedBytes, err := base64.RawURLEncoding.DecodeString(parts[0])
    	if err != nil {
    		return Result{}, err
    	}

    	if err := json.Unmarshal(protectedBytes, &protected); err != nil {
    		return Result{}, err
    	}
    	if protected["alg"] != "ES256" || protected["typ"] != proofType {
    		return Result{}, errors.New("invalid protected header")
    	}
    	kid, ok := protected["kid"].(string)
    	if !ok {
    		return Result{}, errors.New("missing key ID")
    	}

    	if err != nil {
    		return Result{}, err
    	}
    	token, err := jose.ParseSigned(proof, []jose.SignatureAlgorithm{jose.ES256})
    	if err != nil {
    		return Result{}, err
    	}
    	if len(token.Signatures) != 1 ||
    		token.Signatures[0].Protected.Algorithm != "ES256" ||
    		token.Signatures[0].Protected.ExtraHeaders[jose.HeaderType] != proofType ||
    		token.Signatures[0].Protected.KeyID != kid {
    		return Result{}, errors.New("invalid proof header")
    	}
    	payloadBytes, err := token.Verify(key.Key)
    	if err != nil {
    		return Result{}, err
    	}
    	var claims map[string]any
    	if err := json.Unmarshal(payloadBytes, &claims); err != nil {
    		return Result{}, err
    	}
    	if claims["iss"] != expectedIssuer || claims["sub"] != subject || !hasAudience(claims["aud"], audience) {
    		return Result{}, errors.New("invalid registered claims")
    	}
    	iatValue, iatOK := claims["iat"].(float64)
    	expValue, expOK := claims["exp"].(float64)
    	if !iatOK || !expOK || math.Abs(iatValue) > 9007199254740991 || math.Abs(expValue) > 9007199254740991 ||

    func publicKey(jwksBytes []byte, kid string) (jose.JSONWebKey, error) {
    	var set struct {
    		Keys []map[string]any `json:"keys"`
    	}
    	if err := json.Unmarshal(jwksBytes, &set); err != nil {
    		return jose.JSONWebKey{}, err
    	}
    	allowed := map[string]bool{
    		"kty": true, "crv": true, "x": true, "y": true, "alg": true,
    		"kid": true, "key_ops": true, "use": true,
    	}
    	matching := 0
    	for _, raw := range set.Keys {
    		if raw["kid"] == kid {
    			matching++
    		}
    	}
    	if matching != 1 {
    		return jose.JSONWebKey{}, errors.New("key ID must identify exactly one key")
    	}
    	for _, raw := range set.Keys {
    		if raw["kid"] != kid {
    			continue
    		}
    		for name := range raw {
    			if !allowed[name] {
    				return jose.JSONWebKey{}, errors.New("JWK has an unsupported member")
    			}
    		}
    		opsValue, hasOps := raw["key_ops"]
    		ops, opsAreArray := opsValue.([]any)
    		if raw["kty"] != "EC" || raw["crv"] != "P-256" ||
    			(hasAlg(raw) && raw["alg"] != "ES256") ||
    			(hasUse(raw) && raw["use"] != "sig") ||
    			(hasOps && (!opsAreArray || len(ops) != 1 || ops[0] != "verify")) {
    			return jose.JSONWebKey{}, errors.New("JWK is not a public ES256 verification key")
    		}
    		encoded, _ := json.Marshal(raw)
    		var key jose.JSONWebKey
    		if err := json.Unmarshal(encoded, &key); err != nil {
    			return jose.JSONWebKey{}, err
    		}
    		public, ok := key.Key.(*ecdsa.PublicKey)
    		if !ok || public.Curve != elliptic.P256() {
    			return jose.JSONWebKey{}, errors.New("JWK is not an EC P-256 public key")
    		}
    		return key, nil
    	}
    	return jose.JSONWebKey{}, fmt.Errorf("unknown key ID %q", kid)
    }

    	case float64:
    		return value
    	case int:
    		return float64(value)
    	default:
    		return 0
    	}
    }

    func hasAudience(value any, expected string) bool {
    	switch value := value.(type) {
    	case string:
    		return value == expected
    	case []any:
    		for _, item := range value {
    			if item == expected {
    				return true
    			}
    		}
    	}
    	return false
    }
    ```
