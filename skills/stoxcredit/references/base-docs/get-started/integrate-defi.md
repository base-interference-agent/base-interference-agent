# Integrate DeFi

> Add trading with the 0x Swap API, or lending, collateralized borrowing, and a vault-based earn product with the Base Earn API on Base.

Connect your app to DeFi on Base. Let users trade tokens through the 0x Swap API, or lend, borrow against collateral, and deposit once into a vault-based earn product through the [Base Earn API](https://docs.base.org/sdks/base-earn/overview.md). Users sign every transaction from their own wallet.
