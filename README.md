# Base Interference Agent

A skill for AI coding agents (Claude Code, OpenAI Codex CLI, Gemini CLI, Cursor, Aider, and similar).

Status: initial scaffold. Content to be added.

## Install
- Claude Code: copy `skills/base-interference-agent/` to `~/.claude/skills/`
- Codex CLI: copy `skills/base-interference-agent/` to `~/.codex/skills/`
- Other agents: copy `AGENTS.md` to your project root.
